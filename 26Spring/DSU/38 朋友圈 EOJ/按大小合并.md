# 按大小合并
## 我们都知道按秩合并
  rank就是树高度，将低树合并到高树上  
  且因为路径压缩时rank会变，所以最好按秩合并与路径压缩不要一起用~
## 那按大小合并呢？
   其实和按秩合并类似，只不过把小树放到大树上！

## 代码示例
```cpp
void merge(int i,int j,vector<int>& parent,vector<int>& sz)
{
   int a=find(i,parent);
   int b=find(j,parent);
   if(a==b) return;
   if(sz[a]>sz[b]){
    sz[a]+=sz[b];parent[b]=a;}
   else{
    sz[b]+=sz[a];parent[a]=b;}
   return;
}
```
