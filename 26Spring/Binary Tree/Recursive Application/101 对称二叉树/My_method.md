# 思路归纳

## 我的思路
**正如前面解题思路所言**：
```text
           递归
           /  \
          /    \
   分治递归     遍历递归
```

所以我想：
1. 分治递归不太方便，因为这个不可以拆解成子问题
2. 遍历递归中的前序遍历与后序遍历都不太方便
3. 中序遍历含nullptr结点->求出中序遍历后的vector<int>，判断是不是回文
4. 层次遍历含nullptr结点->求出每一层的序列->再判断是不是回文

### 中序遍历：

```[5,2,2,4,null,null,1,null,1,null,4,2,null,2,null]```
