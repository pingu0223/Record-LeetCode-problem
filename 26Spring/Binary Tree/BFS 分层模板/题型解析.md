# 题型解析

## 常见问法
```text
针对某一层进行操作，如求每一层的平均值，求每层最左边的值等等
```
## 核心思路

```找到一个方法，能够记录or确定什么时候层数改变```
1. 先提前维护一个size，在每一次分层前先记录当前的size
2. 之后把每一层的更迭在for循环**for(int i=0;i<size;i++)** 内做完
3. 这样外层while循环每一次都是代表一层，而且初始情况下queue内存储的就是当前层数的值

## 代码分析
```cpp
        queue<TreeNode*>q;
        q.push(root);
        int size;
        while(!q.empty()){
            size=q.size();
            for(int i=0;i<size;i++){
                TreeNode* current=q.front();
                if(current->left!=nullptr){
                    q.push(current->left);
                }
                if(current->right!=nullptr){
                    q.push(current->right);
                }
                q.pop();
            }
        }
```
