# 总结错误思路——关于KMP解法

## 错误1
```cpp
get_next(next,s);
        int i,j;
        int flag=0;
        for(i=s.size()-1;i>=s.size()/2;i--){
            if(next[i]==0){
                flag=1;
                break;
            }
        }
        if(flag==0) return false;
        int len=s.size()-i;
        if((i+1)%len==0)return true;
        return false;
```

```text
我想要通过当next[i]=0，即失配时来找到子字符串，但是，明明失配其实是发生在前半段的
如图所示
         abcabcabc
            abcabcabc
next数组-100123456
若前三个为骨节的话，应该是在c处为0，也就是在一个循环节后出现了next为0的情况
所以出现了问题，因为这种情况根本求不出i 
```

## 错误2
```cpp
for(i=s.size()-1;i>=0;i--){
            if(next[i]==0){
                flag=1;
                cout<<"Yes"<<endl;
                break;
            }
        }
        if(flag==0) return false;
        int len=i;
        cout<<i;
        if(len+1>s.size()/2)return false;
        if((s.size()-i)%len==0)return true;
        return false;
        
    }
```

```text
受前面思路的启发，我想，我们不如把从后往前看遇到的第一个next[i]=0处的i作为len(循环骨节）吧
所以len(循环骨节）=i,最小前缀为s.size()-i
这样我们只需要判断
1）i是不是大于size/2
2）(s.size-i）%i是不是等于0
就好了

看起来很正确，也确实能通过大部分测试点
但是存在一个无法判别的情况
如abac
abac的next数组为-1 0 0 1
这个情况下，我们发现其实它和abab的next数组是一样的，所以我们无法只通过为0来判断
我靠，原来是这种解法的bug，是因为我的kmp算的是-1 0 ，这种情况必须得是公共前后缀长度 0 0开头的那种才可以
我真是服了
```
