# 双指针法

## 核心思想
```text
要在不额外浪费空间的前提下改变字符串，那就直接填充，然后利用双指针（快慢指针法）直接赋值

问题1：
以什么顺序进行赋值？从前往后or从后往前？
从前往后的话：会覆盖数字后的值
从后往前的话：不会覆盖

问题2：
怎么赋值：
一个指针放在原始字符串最末尾处，方便整个遍历
一个指针放在填充后的字符串最末尾处~，方便赋新的值！
```



## 代码示例
```cpp
#include <iostream>
#include <string>

    int j;
    i=s.size()-count*5-1;j=s.size()-1;
    while(i>=0&&j>=0){
        if(s[i]<='9'&&s[i]>='0'){

            s[j]='r';j--;

            s[j]=s[i];

        }
    }

}
```
